# MELODY.BEST

A clean, modern, and customizable browser homepage/start page.

## Features

### 🔍 Multi-Engine Search
- Prominent centered search bar with support for multiple search engines
- Supported providers: Google, Bing, DuckDuckGo, Yahoo, Brave Search, and Ecosia
- Easy provider switching with visual feedback

### ⚙️ Personalization
- **Custom Greeting**: Add your name for a personalized welcome message
- **Clock Display**: Real-time digital clock (toggleable)
- **Date Display**: Current date with day of week (toggleable)
- All settings persist across sessions using localStorage

### 🎨 Appearance Customization
- **Theme Toggle**: Switch between Light and Dark modes
- **Accent Colors**: Choose from preset colors or use a custom color picker
- Beautiful, smooth transitions and animations
- Fully responsive design for desktop and mobile

### 💾 Smart Persistence
- All settings automatically saved to localStorage
- Your preferences remain consistent across browser sessions
- One-click reset to default settings

## Default Settings

On first visit, MELODY.BEST comes configured with:
- Search Provider: Google
- Theme: Dark Mode
- Greeting: "Hello!"
- Clock: Shown
- Date: Shown  
- Accent Color: #6C63FF (pleasant blue)

## Installation & Usage

### Local Deployment
1. Clone this repository
2. Open `index.html` in your web browser
3. Set as your browser's homepage (optional)

### GitHub Pages
This site is ready to be deployed on GitHub Pages:
1. Go to repository Settings → Pages
2. Select the branch to deploy
3. Your site will be available at `https://[username].github.io/MELODY.BEST`
